# HairGuard

🇬🇧 [English version](README.md)

Десктопное приложение для борьбы с трихотилломанией с помощью компьютерного зрения.

HairGuard наблюдает за вебкамерой в фоновом режиме и показывает полноэкранное предупреждение в тот момент, когда кончики пальцев касаются волос — до того, как привычка успела завершиться. Каждый эпизод записывается, чтобы можно было отслеживать прогресс.

---

## Как это работает

На каждый кадр запускаются три модели MediaPipe:

- **PoseLandmarker** — определяет положение головы, плеч и запястий
- **HandLandmarker** — отслеживает 21 точку руки, включая кончики пальцев
- **FaceLandmarker** — строит сетку из 468 точек лица и вычисляет границу лоб/линия роста волос

Каждый кадр проходит через 6-слойный фильтр: рука обнаружена → голова найдена → кончики пальцев выше линии волос → жест щипка → не держит предмет → выдержка времени. Тревога срабатывает только при одновременном прохождении всех слоёв.

---

## Возможности

- Полноэкранный полупрозрачный оверлей с 200+ уникальными фразами (цикличный, без повторов)
- Статистика: сводка за день, сравнение периодов, почасовая гистограмма
- Иконка в системном трее — пауза с автовозобновлением, краткая статистика на наведении
- Режим отладки с визуализацией пайплайна в реальном времени
- Автозапуск при входе в систему (Windows и Linux)
- Защита от нескольких запущенных копий через PID-файл

## Установка

Требуется Python 3.11+.

```bash
# Из PyPI
pip install hairguard

# Из исходников
git clone <repo>
cd hair
pip install -e .

# Linux Wayland — поддержка оверлея
pip install hairguard[wayland]
```

---

## Быстрый старт

```bash
# Запустить обнаружение с иконкой в трее
python -m hairguard start

# Открыть режим отладки (живая камера + отрисовка точек)
python -m hairguard.debugview
```

---

## Команды CLI

```bash
hairguard start                  # Запустить обнаружение (на переднем плане + трей)
hairguard start --camera 1       # Использовать конкретную камеру
hairguard start --background     # Запустить в фоне
hairguard stop                   # Остановить запущенный экземпляр
hairguard status                 # Показать статус, PID, время работы
hairguard cameras                # Список доступных камер
hairguard stats                  # Статистика за сегодня vs вчера
hairguard stats --last 7d        # Последние 7 дней
hairguard stats --from 2026-04-01 --to 2026-04-15
hairguard stats --compare --last 2w
hairguard config                 # Показать текущий конфиг
hairguard config --edit          # Открыть config.yaml в $EDITOR
hairguard autostart on           # Добавить в автозапуск
hairguard autostart off          # Убрать из автозапуска
hairguard debug                  # Открыть режим отладки
```

## Настройка

При первом запуске создаётся файл `~/.hairguard/config.yaml`.

```yaml
camera: 0                        # Индекс камеры (см.: hairguard cameras)

detection:
  trigger_delay_sec: 0.8         # Сколько секунд рука должна быть в зоне волос до тревоги
  dismiss_delay_sec: 2.5         # Сколько секунд тревога держится после ухода руки
  fps: 10                        # Кадров в секунду для обработки
  min_confidence: 0.5            # Минимальная уверенность для доверия точке
  pinch_threshold: 0.4           # Расстояние большой-указательный / размер кисти
                                 #   — ниже порога = щипок
  min_presence_score: 0.7        # Минимальный presence score кончика пальца
  hair_zone_offset: 0.4          # Насколько выше лба расширить зону волос
                                 #   (доля ширины плеч)

alert:
  opacity: 0.7                   # Прозрачность оверлея (0.0–1.0)
  text_color: "#ffffff"          # Цвет текста в тревоге

pause:
  auto_resume_minutes: 15        # Пауза через трей автоматически снимается через N минут
```

Некорректные значения выводятся при запуске; поле сбрасывается к значению по умолчанию.

## Пайплайн обнаружения

Каждый кадр проходит 6 слоёв, прежде чем сработает тревога:

| Слой | Проверка |
|------|----------|
| 1 | Рука обнаружена с достаточной уверенностью |
| 2 | Голова найдена (уши + сетка лица) |
| 3 | Зона волос вычислена по контуру лба FaceMesh |
| 4 | Кончик большого или указательного пальца внутри зоны волос |
| 5 | Жест щипка (расстояние большой-указательный ниже порога) |
| 6 | Выдержка — состояние удерживается `trigger_delay_sec` секунд |

Фильтр захвата предметов отличает закручивание волос от удержания объекта: если средний, безымянный или мизинец согнуты (2 и более), кадр трактуется как «держит предмет» и игнорируется.

Если HandLandmarker теряет руку (например, рука за головой), Pose-запястье используется как дополнительный сигнал с низкой уверенностью.

## Режим отладки

```bash
python -m hairguard.debugview
# или
hairguard debug
```

Показывает живое окно камеры с:

- Скелетом кисти из 21 точки
- Полигоном зоны волос
- Индикатором щипка и статусом сгиба каждого пальца
- Подсветкой кончиков пальцев внутри зоны
- Статусом прохождения каждого слоя

## Статистика

```bash
hairguard stats                        # Сегодня vs вчера
hairguard stats --date 2026-04-10      # Конкретная дата
hairguard stats --last 7d              # Последние 7 дней
hairguard stats --last 4w              # Последние 4 недели
hairguard stats --compare --last 2w    # Сравнить два периода подряд
```

Вывод включает количество эпизодов, суммарное время, среднюю длительность и почасовую гистограмму. Тренды подсвечены цветом (зелёный = улучшение).

Подсказка иконки в трее показывает текущую сводку: «Сегодня: 14 эпизодов, 5м 20с».

Эпизоды хранятся в `~/.hairguard/hairguard.db` (SQLite).

## Поддержка платформ

| Платформа | Статус |
|-----------|--------|
| Windows 10/11 | Полная поддержка |
| Linux (X11) | Полная поддержка |
| Linux (Wayland) | Поддерживается через `gtk-layer-shell` — установить: `pip install hairguard[wayland]` |

На Wayland без `gtk-layer-shell` оверлей использует базовый tkinter, который может не оставаться поверх окон. При запуске выводится предупреждение.

## Зависимости

| Пакет | Назначение |
|-------|-----------|
| mediapipe | Определение позы, рук и лица |
| opencv-python | Захват с камеры |
| pystray + Pillow | Иконка в системном трее |
| pyyaml | Файл конфигурации |
| colorama | Цветной вывод в терминале |
| plyer | Системные уведомления |
| tkinter | Оверлей тревоги (встроен в Python) |

Опционально: `PyGObject` — бэкенд оверлея для Wayland (`pip install hairguard[wayland]`).
