# hairlab

Сбор и разметка данных для обучения модели распознавания кручения волос.
Отдельный пакет: `hairguard` работает без него, зависимость идёт только в одну
сторону — `hairlab` переиспользует детекторы приложения, но не наоборот.

## Сбор клипов

Запись включается двумя способами, оба ведут к одному и тому же:

```bash
hairguard collect on       # или python -m hairguard collect on
hairguard collect off
hairguard collect status   # включено ли, работает ли приложение, сколько клипов
```

и пункт **«Сбор данных»** в трее HairGuard.

Состояние хранится в `~/.hairguard/collect.state`, работающее приложение
сверяется с ним примерно раз в секунду. Поэтому команду можно дать и до
запуска приложения, и во время работы, а `collect status` отвечает на вопрос
«а оно вообще писало?» — раньше на него нельзя было ответить никак.

По умолчанию выключено, и при **каждом** запуске приложения снова выключается:
фоновый автозапуск не должен молча начать писать вас с камеры.

Пока сбор выключен, ни один кадр не попадает даже в оперативную память.

Когда сбор идёт, приложение печатает «пульс»: видна ли рука в зоне, сколько
кадров накоплено к следующему клипу и сколько клипов уже записано. Молчание
перестаёт быть двусмысленным.

Когда включён, работает правило:

- кадры буферизуются, только пока пальцы находятся в зоне волос;
- любой кадр без руки у головы очищает буфер целиком;
- когда накопились непрерывные 2 секунды — буфер сохраняется как клип;
- после сохранения пауза **10 секунд** до следующего, иначе один длинный
  эпизод даёт пачку почти одинаковых клипов: время на разметку они съедают,
  а модели не сообщают ничего нового.

## Сбор не мешает основной функции

Оповещение — то, ради чего приложение существует; сбор данных занятие
побочное. Поэтому:

- состояние оповещения обновляется **до** любой работы по сбору;
- кодирование двадцати JPEG уходит на рабочий поток (`hairlab.writer`) —
  в главном потоке остаётся 0.7 мс вместо 17;
- любая ошибка записи гасится и попадает в лог, но не поднимается выше:
  переполненный диск — повод потерять клип, но не повод перестать
  предупреждать вас;
- при включении записи не показывается системное уведомление: на Windows
  оно создаёт собственное окно, а рисковать полноэкранным оповещением ради
  этого незачем.

Жест при этом **не оценивается**: сохраняется всё, где рука у головы, включая
случаи, когда вы ничего не крутите. Иначе датасет унаследовал бы ошибки
текущего детектора и никогда не показал бы модели, как выглядит «просто держу».

## Что лежит в клипе

Каталог `~/.hairguard/clips/<id>/`: 20 кадров JPEG 256×256 плюс `meta.json`.
Порядка 150–250 КБ на клип.

Вырезка **центрирована на кисти**, которая находится в зоне, и её размер
берётся из размаха самой кисти. Поэтому рука занимает примерно 55% кадра
независимо от того, сидите вы близко к камере или далеко. Вырезать голову и
руки вместе — первая напрашивающаяся идея — давало клипы, где в одном образце
кисть во весь кадр, а в соседнем размером с ноготь; обучением это не лечится.

В `meta.json` на каждый кадр пишется:

| поле | что это |
|---|---|
| `t` | монотонная метка времени |
| `hand` | 21 точка кисти, `[x, y, z]`, координаты полного кадра |
| `pose` | нос, уши, плечи — система отсчёта для нормализации |
| `forehead` | линия роста волос, когда лицо распознано |
| `box`, `source_px` | рамка выреза и её реальный размер в пикселях |

Плюс на клип целиком: `fps_measured` и `duration_sec`, посчитанные из меток
времени. Настроенный fps — это пожелание, которое цикл детекции почти никогда
не выполняет, поэтому скорость воспроизведения и любые временные признаки
считаются по факту.

**Координаты — это и есть обучающий вход первой модели.** Она учится на
последовательностях точек, а не на пикселях; изображения нужны, чтобы
размечать глазами и чтобы позже можно было добавить визуальную ветку.
Извлекать точки потом из вырезанного кадра строго хуже, чем сохранить их в
момент съёмки, когда они точны.

Проверить здоровье датасета: `python -m hairlab stats` покажет, сколько клипов
без координат (не годятся для обучения) и сколько снято с увеличением
(реальной детализации нет).

## Разметка

```bash
python -m hairlab label          # интерфейс на http://127.0.0.1:8765/
python -m hairlab label --port 9000 --no-browser
python -m hairlab stats          # прогресс разметки в консоли
```

Клавиатура: `1`–`5` — метка, `пробел` — пауза, `←`/`→` — по кадрам,
`⌫` или `U` — отменить последнюю метку.

Метки: кручу, просто держу, чешу, расчёска/предмет, не разобрать.
«Не разобрать» существует, чтобы сомнительные клипы исключались из обучения,
а не попадали в него догадками.

Метки хранятся в `~/.hairguard/labels.db` (SQLite), отдельно от кадров —
переразметка не трогает изображения.
