# Геометрия зоны волос — математическая модель

## Задача

Определить двумерную область на изображении с камеры, в которой находятся волосы пользователя, при произвольном положении головы и камеры. Область должна адаптироваться к наклону головы набок (крен), наклону вперёд (тангаж) и повороту в сторону (рыскание).

## Входные ориентиры

Из MediaPipe PoseLandmarker (нормализованные экранные координаты 0–1, ось Y направлена вниз):

- **N** — нос
- **L** — левое ухо
- **R** — правое ухо
- **SL** — левое плечо
- **SR** — правое плечо

Каждый ориентир имеет оценку уверенности. Дополнительно FaceLandmarker предоставляет контур лба для вторичной фильтрации.

## Алгоритм

### Шаг 1: Горизонталь камеры по плечам

Линия плеч определяет понятие «горизонтали» для камеры — это работает независимо от положения камеры (спереди, сбоку, сверху).

```
camera_horizontal = normalize(SR - SL)
```

**Защитная проверка:** если уверенность любого из плеч < 0.5, использовать экранную горизонталь `(1, 0)`.

### Шаг 2: Векторы ориентации головы

```
ear_vec = R - L
ear_distance = |ear_vec|
```

**Защитная проверка:** если уверенность любого из ушей < 0.5 или `ear_distance < shoulder_distance * 0.2`, использовать `camera_horizontal` в качестве горизонтали головы.

```
head_horizontal = normalize(ear_vec)
```

### Шаг 3: Центр головы и масштаб

```
head_center = midpoint(L, R) = (L + R) / 2
shoulder_distance = |SR - SL|
head_scale = max(ear_distance, shoulder_distance * 0.45)
```

Коэффициент 0.45 взят из антропометрических данных: ширина головы ≈ 45% биакромиального расстояния. Функция `max` обеспечивает корректную работу при повороте головы в сторону (когда расстояние между ушами уменьшается из-за перспективного сокращения) — в этом случае в расчёт берётся оценка по плечам.

### Шаг 4: Вектор «вверх» (в направлении макушки)

В экранных 2D-координатах (ось Y направлена вниз) поворот вектора на 90° против часовой стрелки даёт визуально «верхний» перпендикуляр:

```
up_candidate = (-ear_vec.y, ear_vec.x)   # 90° CCW в экранных координатах = визуальный «верх»
up_candidate = normalize(up_candidate)
```

**Определение знака по плечам:** центр головы расположен выше центра плеч в экранном пространстве. Это используется для проверки знака:

```
shoulder_center = midpoint(SL, SR)
down_vec = shoulder_center - head_center
```

Если `dot(up_candidate, down_vec) > 0`, значит `up_candidate` направлен к плечам (то есть вниз) — нужно перевернуть:

```
if dot(up_candidate, down_vec) > 0:
    up_candidate = -up_candidate
```

**Резервный вариант для камеры сверху:** если `|down_vec| < 0.05 * head_scale`, голова и плечи совпадают в проекции (камера находится над головой). Использовать экранный «верх»:

```
if |down_vec| < 0.05 * head_scale:
    up_candidate = (0, -1)  # экранный верх (отрицательный Y)
```

Итог: `up_vec = normalize(up_candidate)`

### Шаг 5: Определение тангажа (декомпозиция)

Сырой вектор `face_vec = N - head_center` смешивает рыскание и тангаж. Разложим их:

```
face_vec = N - head_center

# Проецируем face_vec на up_vec, получая знаковую компоненту тангажа.
# Положительное значение = нос ниже середины между ушами вдоль up_vec (нейтраль/наклон назад)
# Отрицательное значение = нос выше середины между ушами (сильный наклон назад — взгляд в потолок)
# Около нуля = нос на уровне ушей (наклон вперёд — лицо смотрит вниз)
pitch_component = -dot(face_vec, up_vec)   # инвертируем, чтобы наклон вперёд давал малые/отрицательные значения
pitch_ratio = pitch_component / head_scale
```

Ограничение: `pitch_ratio = clamp(pitch_ratio, -0.3, 0.6)`

- Нейтральная поза: pitch_ratio ≈ 0.3 (нос ниже ушей)
- Наклон вперёд: pitch_ratio → 0 или отрицательный (нос поднимается к уровню ушей)
- Наклон назад: pitch_ratio → 0.5+ (нос опускается ещё ниже ушей)

```
# Коэффициент тангажа: расширяем зону волос при наклоне вперёд (затылок открывается)
pitch_factor = 1.0 + max(0, 0.3 - pitch_ratio) * 1.5
```

### Шаг 6: Зона волос как повёрнутый эллипс

Зона волос — это эллипс, центр которого смещён вверх от центра головы и выровнен по ориентации головы:

```
# Смещение от head_center к hair_center (в направлении up_vec)
base_offset = head_scale * 0.5
pitch_offset_bonus = max(0, 0.3 - pitch_ratio) * head_scale * 0.3
hair_center = head_center + up_vec * (base_offset + pitch_offset_bonus)

# Полуоси эллипса
semi_width = head_scale * 0.55    # вдоль head_horizontal (направление ухо–ухо)
semi_height = head_scale * 0.6 * pitch_factor   # вдоль up_vec (в сторону макушки)
```

Примечание: semi_height > semi_width, поскольку волосы простираются больше по вертикали (от лба до затылка), чем по горизонтали.

### Шаг 7: Проверка принадлежности точки эллипсу

Чтобы проверить, находится ли точка P = (x, y) внутри зоны волос:

```
d = P - hair_center

# Проецируем на оси эллипса
proj_w = dot(d, head_horizontal) / semi_width
proj_h = dot(d, up_vec) / semi_height

in_zone = (proj_w² + proj_h²) <= 1.0
```

### Шаг 8: Фильтр по лбу (опциональное уточнение)

Если FaceLandmarker доступен, использовать контур лба для исключения области лица из эллипса. Это предотвращает ложные срабатывания при касании лба (а не волос):

```
if face_detected AND face.is_above_forehead(x, y) is False:
    return False  # точка находится на лице, а не в волосах
```

Этот фильтр аддитивный — он только убирает ложноположительные результаты, но никогда не блокирует истинные.

## Шаг 9: Временное сглаживание

Дрожание ориентиров вызывает покадровое «вибрирование» эллипса. Применяем экспоненциальное скользящее среднее (EMA) ко всем вычисленным значениям:

```
alpha = 0.3  # константа сглаживания (новое = alpha * текущее + (1 - alpha) * предыдущее)

hair_center = ema(hair_center, alpha)
semi_width = ema(semi_width, alpha)
semi_height = ema(semi_height, alpha)
up_vec = normalize(ema(up_vec, alpha))  # интерполируем, затем нормализуем
head_horizontal = normalize(ema(head_horizontal, alpha))
```

При ~15 FPS значение alpha=0.3 даёт эффективное окно около 3 кадров — достаточно отзывчиво для обнаружения в реальном времени и при этом устраняет однокадровые выбросы.

На первом кадре (когда предыдущих значений нет) используются значения текущего кадра напрямую, без сглаживания.

## Визуальное представление

Зона волос на отладочном виде:
- Рисуем контур эллипса (повёрнутый в соответствии с ориентацией головы)
- Заливаем полупрозрачным цветом
- Отмечаем hair_center крестом
- Рисуем up_vec стрелкой от head_center

## Граничные случаи и резервные варианты

| Случай | Симптом | Решение |
|---|---|---|
| Камера сверху | `\|down_vec\|` близко к нулю | Перейти на экранный верх `(0, -1)` |
| Одно ухо перекрыто | `ear_distance` очень мало | Использовать `shoulder_distance * 0.45` как head_scale; использовать `camera_horizontal` как ось головы |
| Голова повёрнута на 90° | Уши сокращаются перспективно, `ear_vec` уменьшается | `max(ear_distance, shoulder_distance * 0.45)` покрывает этот случай |
| Голова полностью наклонена вперёд | Нос совпадает с серединой между ушами | `pitch_factor` увеличивается, расширяя зону к затылку |
| Наклон назад | Нос выше середины между ушами | `pitch_ratio` увеличивается, `pitch_factor` остаётся 1.0 (расширение не нужно) |
| Оба уха перекрыты | `ear_vec` и `head_center` ненадёжны | Установить `head_center = N` (нос), `head_scale = shoulder_distance * 0.45`, `head_horizontal = camera_horizontal` |
| Одно плечо перекрыто | `camera_horizontal` ненадёжна | Перейти на экранную горизонталь `(1, 0)` |

## Сводка констант

| Константа | Значение | Источник |
|---|---|---|
| Соотношение ширины плеч к ширине головы | 0.45 | Антропометрические данные |
| Минимальное расстояние между ушами | `shoulder_distance * 0.2` | Защита от перспективного сокращения ушей |
| Смещение центра волос | `0.5 * head_scale` | Макушка ≈ на 50% выше середины между ушами |
| Полуширина эллипса | `0.55 * head_scale` | Ширина волос ≈ ширина головы |
| Полувысота эллипса | `0.6 * head_scale * pitch_factor` | Волосы простираются больше по вертикали |
| Порог расширения по тангажу | 0.3 | Ниже этого pitch_ratio голова наклонена вперёд |
| Минимальная длина down_vec | `0.05 * head_scale` | Защита для камеры сверху |
| Порог уверенности | 0.5 | Надёжность ориентира |
